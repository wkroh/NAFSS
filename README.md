# منصة نواتج التعلم لاختبارات نافس الوطنية - الصف التاسع (الثالث متوسط) 🇸🇦
### استناداً إلى الإطار المرجعي لهيئة تقويم التعليم والتدريب (ETEC 2023)

منصة تعليمية وتدريبية تفاعلية متكاملة تركز حصرياً على نواتج التعلم والمعايير المخصصة لـ **الصف التاسع** في مجال **العلوم الطبيعية** (علوم الحياة، العلوم الفيزيائية، وعلوم الأرض والفضاء).

---

## 🌟 مميزات المنصة

1. **تحليل واستخلاص دقيق لمحتوى الصف التاسع**:
   - تم استخلاص جميع نواتج التعلم والمؤشرات الرسمية الواردة في وثيقة هيئة تقويم التعليم والتدريب (الجدول رقم 2 للصف التاسع، الصفحات 14 إلى 24).
   - تقسيم المحتوى إلى مسارات واضحة مع إبراز رموز النواتج (مثل `1-1-1-5-9`, `2-1-2-5-9`, `6-2-3-5-9`).

2. **شرح مفاهيمي تفاعلي لكل درس**:
   - تغطية شاملة للمفاهيم الأساسية، القوانين الرياضية، النماذج، والمقارنات العلمية.
   - بطاقات المفاهيم الذهبية لتلخيص أهم النقاط قبل الاختبار.

3. **أسئلة تدريبية فورية مصنفة إدراكياً**:
   - كل درس يحتوي على أسئلة تحقق مصنفة وفق المستويات الإدراكية الثلاثة للاختبارات الوطنية:
     - **المعرفة (Knowledge - 40%)**: تذكر واستدعاء المفاهيم.
     - **التطبيق (Application - 40%)**: حل المسائل وتطبيق القوانين.
     - **الاستدلال (Reasoning - 20%)**: التفكير الناقد واستخلاص النتائج.
   - تصحيح فوري وشرح علمي دقيق لسبب صحة أو خطأ كل خيار.

4. **محاكي الاختبار الوطني الشامل (نافس)**:
   - 30 سؤالاً شاملاً تحاكي بيئة الاختبار الحقيقي.
   - مؤقت زمني تنازلي (30 دقيقة).
   - خارطة أسئلة تفاعلية مع إمكانية تمييز الأسئلة للمراجعة.
   - تقرير أداء تحليلي شامل بعد إنهاء الاختبار:
     - النسبة المئوية وتصنيف المستوى (متقدم / متمكن / أساسي / دون الأساسي).
     - تحليل الأداء بحسب المجالات العلمية الثلاثة.
     - تحليل الأداء بحسب المستويات الإدراكية.
     - مراجعة كاملة لجميع الأسئلة مع الإجابات النموذجية.

5. **بطاقات المراجعة السريعة (Interactive Flashcards)**:
   - بطاقات تفاعلية قابلة للتقليب ثلاثي الأبعاد للمراجعة السريعة للمصطلحات والقوانين مع إمكانية الفلترة والخلط العشوائي.

6. **تصميم عصري ودعم متكامل**:
   - واجهة مستخدم عربية بالكامل (RTL) مع خطوط مريحة للعين.
   - دعم الوضع الليلي (Dark Mode) والنهاري (Light Mode).
   - شريط تقدم ذكي يحفظ إنجاز الطالب في المتصفح محلياً (`LocalStorage`).
   - متوافق تماماً مع الهواتف الذكية والأجهزة اللوحية والحواسيب.

7. **روابط التدريب الوطنية**:
   - ربط مباشر ومميز مع منصة التدريب الوطنية: **[nafss.pro](https://nafss.pro)**.

## 🌐 كيفية رفع المشروع وتفعيله على استضافة GitHub Pages

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح حسابك على [GitHub](https://github.com) وسجل الدخول.
2. انقر على الزر الأخضر **New** لإنشاء مستودع جديد.
3. اكتب اسم المستودع (مثلاً: `etec-grade9-nafss`).
4. اختر أن يكون المستودع **Public** (عام) حتى تعمل الاستضافة المجانية، ثم انقر **Create repository**.

### الخطوة 2: رفع الملفات عبر الطرفية (Git Commands)
افتح موجه الأوامر (PowerShell أو Terminal) في مجلد المشروع، ونفذ الأوامر التالية:

```bash
# الانتقال لمجلد المشروع
cd "C:\Users\Wkroh\.gemini\antigravity\scratch\etec-grade9-nafss"

# ربط المستودع برابط مستودعك على قيت هاب (استبدل YOUR_USERNAME باسم مستخدمك)
git remote add origin https://github.com/YOUR_USERNAME/etec-grade9-nafss.git

# تسمية الفرع الرئيسي main
git branch -M main

# رفع الملفات
git push -u origin main
```

### الخطوة 3: تفعيل استضافة GitHub Pages مجاناً
1. في صفحة مستودعك على GitHub، انقر على تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية اليسرى، انقر على **Pages**.
3. تحت قسم **Build and deployment**:
   - اضبط **Source** على `Deploy from a branch`.
   - اضبط **Branch** على `main` والمجلد على `/ (root)`.
4. اضغط على زر **Save**.
5. انتظر من 1 إلى 2 دقيقة، وسيظهر لك رابط موقعك المباشر في أعلى الصفحة مثل:
   `https://YOUR_USERNAME.github.io/etec-grade9-nafss/`
